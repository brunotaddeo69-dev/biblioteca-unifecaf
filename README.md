# Biblioteca Digital UniFECAF

Projeto acadêmico demonstrativo de uma interface de biblioteca digital desenvolvida exclusivamente com HTML5 e CSS3.

## Arquivos
- `index.html`: estrutura semântica da página.
- `css/style.css`: identidade visual, componentes e layout responsivo.

## Executar localmente
Abra `index.html` em um navegador moderno. A tipografia usa Google Fonts, com alternativas locais.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
4. Aguarde a publicação e teste o endereço no computador e no celular.

## Observações
Esta é uma interface demonstrativa, não uma plataforma funcional de empréstimo ou consulta bibliográfica. Os livros apresentados são exemplos conceituais; a busca não consulta uma base de dados. O protótipo oficial de baixa fidelidade não foi disponibilizado no material utilizado para esta versão.
